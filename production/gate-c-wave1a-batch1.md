## 3. 诊断：为什么 σ 未改善？

### 3.1 预期 vs 实际

| 假设 | 预期 | 实际 |
|---|---|---|
| 更多真技能英雄 → T4 占比下降 | σ 改善 | σ 不变（26.3pp） |
| T4→T1 转化 → 弱英雄减少 | <40% 占比下降 | 反而上升（23.7%→28.2%） |

### 3.2 根因

| 因素 | 机制 | 贡献 |
|---|---|---|
| **T1 挤压效应** | 新 T1 加入增加高胜率池，T4 相对更弱（52.4%，↓2.1pp） | 抵消 T4 占比下降的效果 |
| **骰值结构未变** | 刺客 2d8→36.0 仍超配额带，T4 骰均值仍低于 T1 | σ 主要矛盾未解 |
| **CD 合规不变** | T1/T2 卡片的 CD 拖累 C-14（79.4% 不变） | 无贡献 |
| **采样噪声** | 131 样本，~±2pp 噪声带 | 实际变化在噪声内 |

### 3.3 量化

- T4 模板卡占比从 65%→60%（-5pp），但 T1 vs T4 从 89.3%→91.7%（+2.4pp）
- 两者方向相反，净效果：σ 不变
- 26 个新 LoL 英雄带来的增量不足以改变全局分层格局

### 4.2 整体判定

# ⚠️ σ 未改善 — 26.3pp，方向没错但幅度不足

**判定**：σ 维持 26.3pp，未达 ≤20pp 目标。增加真技能英雄数量（T4→T1 转化）虽然提高了卡片质量，但由于新增 T1 进一步挤压 T4 生存空间（T1vsT4 从 89.3%→91.7%），方差并未缩小。需要结构性的 T4 赋能或骰值/冷却重新校准，而非单纯增加 T1 数量。

### 4.3 建议

| 优先级 | 动作 | 预期 |
|---|---|---|
| **P0** | 刺客 2d8→2d6（期望 36→28，入配额带） | T1 σ 改善 |
| **P0** | T4 骰值提升或增加被动/机制补偿 | T1vsT4 差距缩小 |
| **P1** | T1/T2 卡片 CD 合规修复（C-14 从 79.4% 提升） | C-14 → 目标 100% |
| **P2** | 评估是否继续 Wave 1-A 第 2 批（其他游戏） | 或先做结构性修复 |
