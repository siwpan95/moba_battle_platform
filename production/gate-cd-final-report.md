### 4.2 整体判定

# **⚠️ CONCERNS**

### 4.3 理由

**Wave 0 的核心目标——消灭 T3 残卡层——已完成。** 707 张残卡归零、378 张死数据清除、3024 条冗余条目移除。这消除了 42.6% 英雄"没技能可打"的结构性缺陷，σ 从 33.3pp 降至 25.8pp（↓7.5pp）。

**但 σ 未达 20pp 的 Wave 0 阶段目标（差距 5.8pp）。** 根因是 T4 模板技能的 CD/骰期望仍未与引擎节奏（`[0,1,2,4]` 冷却 + 29.4 骰基准）对齐。具体表现为：

1. **C-13 骰期望合规率仅 49.6%**：一半模板技能的骰期望不在 24-34 配额带
2. **C-14 CD 合规率 79.4%**：~20% 模板技能的平均 CD > 3.0 或槽 0 CD ≠ 0
3. **C-6 T1 vs T4 = 84.8%**：模板技能整体比真实技能弱 ~35pp

**Gate D 质量护栏完好**——常量未漂移、pytest 55/55、check_cards 零告警。

### 4.4 剩余差距来源量化

从 25.8pp → 20pp 的 5.8pp 差距分解：

| 来源 | 贡献估计 | 修复方向 |
|---|---|---|
| T4 骰期望偏离配额带 | ~3pp | C-13 修复：模板骰值标定至 24-34 |
| T4 CD 偏离引擎节奏 | ~2pp | C-14 修复：模板 CD 标定至 `[0,1,2,4]` 邻域 |
| T1/T4 样本内离散 | ~1pp | 需 Wave 1 真实技能升级缩小 tier 间差距 |

### 4.5 放行建议

**Wave 0 数据再生可以合入。** 理由：
- T3 归零是质的飞跃（σ↓7.5pp），为后续 Wave 1 奠定了基础
- Gate D 护栏完好，不会引入回归
- 剩余 σ 差距完全落在模板技能的 CD/骰值标定——属于 GDD §2.2 的 Wave 0-D 子项（"模板 CD 重标定"），本质是数据问题，不是结构问题

**但合入后必须立即执行：**

| 优先级 | 动作 | 预期效果 |
|---|---|---|
| **P0** | 模板 CD 重标定至 `[0,1,2,4]` 邻域（Wave 0-D） | σ → ≤22pp |
| **P0** | 模板骰期望重标定至 24-34 配额带（Wave 0-C 已补 `dice_count`，需验证） | σ → ≤20pp |
| **P1** | 建立基线胜率快照（补 D-1/D-2 技术债） | 后续变更可做 Δ 对比 |
| **P1** | 推进 Wave 1 方案 B（+317 条源技能） | 真实覆盖 34.6% → 53.7%，σ → ≤15pp |
