## 3. 诊断：σ 为何未改善？

### 3.1 预期 vs 实际

| 假设 | 预期 | 实际 |
|---|---|---|
| LoL 100% 覆盖 → T1 占比大幅提升 | σ 改善（T4 挤压减少） | σ 微升 +0.3pp |
| 更多真技能 → 弱英雄减少 | <40% 占比下降 | 持平 28.2% |
| T1 池扩大 → T1 内部竞争加剧 | T1 均值下降 | ✅ 77.6%→72.1%（-5.5pp） |

### 3.2 根因分析

| 因素 | 机制 | 贡献 |
|---|---|---|
| **T1 内部稀释** | LoL +90 T1 加入后，T1 池从 ~399→490，T1 内部胜率从 57.1%→54.1% | 正面：T1 极端值被稀释 |
| **T4 被动弱化** | T4 在更大 T1 池中相对竞争力下降（52.4%→51.2%） | 负面：抵消 T1 改善 |
| **骰值/CD 结构未变** | C-13/C-14 合规率不变（73.3%/79.4%） | σ 主因未解 |
| **采样噪声** | 131 样本，~±2pp 噪声带 | +0.3pp 在噪声内 |

### 3.3 量化总结

- T1 平均胜率 -5.5pp（77.6%→72.1%）：正面信号，但不足以拉动 σ
- T1 vs T4 -4.4pp（86.4%→82.0%）：对位差距缩小，正面
- T4 占比 -6pp（60%→54%）：结构改善，正面
- σ +0.3pp（26.3→26.6）：负面但在噪声带内
- **净效果：广度策略边际收益递减，需结构性修复**

### 4.2 整体判定

# ⚠️ σ=26.6pp（+0.3pp，噪声持平）— 广度策略边际递减

**判定**：LoL 100% 真技能覆盖（81→171，+90 T1）未能改善 σ。虽然 T1 平均胜率下降 5.5pp、T1vsT4 缩小 4.4pp 均为正面信号，但 σ 从 26.3pp 微升至 26.6pp（噪声带内）。骰值合规（73.3%）和 CD 合规（79.4%）仍然是不变的结构性瓶颈。增加真技能英雄数量的边际收益已近于零——下一步必须从骰值配额 + CD 校准入手。
